# Seekho Test

Seekho Test is a simple Android application created as part of a practical test.  
It demonstrates the use of Kotlin and modern Android development tools.

---

## Features

- Clean and simple Android project setup  
- Written in Kotlin  
- Uses modern Android development practices  
- Ready for extension and further development  

---

## Tech Stack

- **Language:** Kotlin  
- **Build System:** Gradle (Kotlin DSL)  
- **Minimum SDK:** 21  
- **Target SDK:** 34  
- **Android Components:** ViewModel, LiveData, Jetpack libraries
